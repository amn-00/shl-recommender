A conversational agent for SHL's assessment catalogue. It asks a clarifying question when a brief is vague, then returns a shortlist drawn only from the 84 assessments it actually has on file.

FastAPI · Groq Llama 3.3 · no LangChain /API docs /Source

Enter to send · Shift + Enter for a new line

Every recommendation is checked against the catalogue before it is returned, so the agent cannot invent an assessment that does not exist.
Running on a free instance — the first request after a quiet spell takes about a minute to wake.
